# Addis Eats

A React restaurant menu built as part of IBT Module 3 Day 27.

## Features

- Reusable `Dish` component
- PropTypes validation
- Default currency set to ETB
- Conditional spicy badge
- Reusable `Card` component using `children`
- Menu data stored separately in `data.js`
- Category-based menu filtering
- Empty state when no dishes match
- Stable keys using dish IDs
- Responsive restaurant-style design
- Ethiopian food images

## Technologies

- React
- JavaScript
- CSS
- Vite
- PropTypes
