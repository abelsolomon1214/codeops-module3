# Question 6 - PropTypes and Dish Menu

A simple React application that uses PropTypes to validate component props and renders a list of dishes.

## Features

- Reusable `Dish` component
- PropTypes validation
- Required `name` and `price` props
- Optional `spicy` prop
- Dish list rendered with `map()`
- Unique `id` used as the React key
- Conditional "Spicy" badge
