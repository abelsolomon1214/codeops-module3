# Addis Eats - React Dish Menu

A simple React application that displays Ethiopian dishes using reusable components and JavaScript array mapping.

## Features

- Reusable `Dish` component
- Dish data stored in an array
- Dishes rendered using `map()`
- Unique keys for each dish

## How to Run

Install the dependencies:

```bash
npm install

Start the development server:

npm run dev

Open the local URL shown in the terminal.
