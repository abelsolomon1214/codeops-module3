# Day 31 - Question 1: React Router Setup

## Objective

Install `react-router-dom` and set up client-side routing with `BrowserRouter`.

## What I Built

This exercise demonstrates:

* `BrowserRouter`
* `Routes`
* `Route`
* `Link`
* Three basic application routes

## Routes

| Path    | Page      |
| ------- | --------- |
| `/`     | Home Page |
| `/menu` | Menu Page |
| `/cart` | Cart Page |

## Technologies

* React
* Vite
* React Router DOM v6
* JavaScript
* CSS

## How to Run

```bash
npm install
npm run dev
```

Then open the local Vite URL in the browser.

## Learning Outcome

I learned how to configure client-side routing in a React application using React Router and how to navigate between pages without a full browser page reload.
